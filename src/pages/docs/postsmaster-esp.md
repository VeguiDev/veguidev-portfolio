# Información sobre el envío de correos – vegui.dev

Este dominio envía **correos electrónicos transaccionales legítimos** desde su propia infraestructura para sitios desarrollados por Juan Manuel Menta.

## 📌 ¿Qué tipo de correos enviamos?

- Formularios de contacto desde sitios web
- Correos de recuperación de contraseña
- Invitaciones o confirmaciones de acceso a plataformas
- Notificaciones puntuales por actividad del usuario

No realizamos campañas de marketing ni envíos masivos.

## 📈 Frecuencia y volumen

- Volumen bajo
- Correos enviados manualmente por usuarios o como respuesta a acciones específicas
- No se utiliza para boletines ni promociones
